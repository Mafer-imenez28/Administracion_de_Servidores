# Tarea 3.1: Automatización de administración de usuarios, grupos y políticas de acceso

## Descripción
Este directorio contiene los scripts de PowerShell desarrollados para la automatización de creación de usuarios locales, asignación de grupos secundarios, carpetas home y directivas de seguridad en Windows.

## Archivos
* `automatizar_usuarios.ps1`: Script principal de automatización en PowerShell.
